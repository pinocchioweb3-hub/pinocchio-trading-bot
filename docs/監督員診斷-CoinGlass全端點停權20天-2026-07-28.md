## 為什麼 20 天沒被抓到（這是流程缺陷，不只是 bug）

1. **失敗被包成成功**：`errored=False` + `items=[]`，任何看 error 旗標的監控都看不到。
2. **既有定案把它歸類成雜訊**：`source_down - coinglass` 之前被判為「可接受降級（L2 免疫）」（見 dq-alert 定案）。那個判斷在「偶爾缺欄位」的世界是對的，在「整個帳號被停權」的世界是錯的。**該定案的適用前提已經不成立。**
3. **第一個成立的解釋吃掉了注意力**：deepdive 停產在 7/08 就有一個看起來完全合理、而且是真的的解釋（LLM 會員過期），於是沒有人再往上游追第二個原因。**一個症狀有一個已確認的原因，不代表沒有第二個。** 這次是 LLM 恢復後症狀沒有跟著消失，才把第二層翻出來。
4. **ledger 只證明 daemon 有產出，不證明每條產線都在動**：ADVANCING 是真的（有 commit、有輸出），但一條旗艦產線停了 20 天，state 仍是 ADVANCING。
