## 這是什麼

24/7 運行的加密貨幣（＋美股永續）訊號機器人，透過 Telegram 推送：

- 🎯 **進場訊號** — SMC 結構分析 + 多過濾器投票制，附進場區間 / SL / TP1-3 / 建議槓桿
- 📊 **歷史類比** — 每筆訊號附「相同條件下的歷史勝率」（誠實樣本數，不灌水）
- ⚡ **全市場異常掃描** — 350+ 永續合約的價格 / OI / 資金費率異常即時警報
- 📅 **事前風險預警** — 經濟數據日曆（CPI/FOMC 靜默期）+ 代幣解鎖黑名單
- 📰 **消息面 AI 過濾** — Truth Social / X 高訊號帳號，AI 評估影響後繁中推送
- 🖼 **SMC 圖表標記** — K 線圖自動標 HH/HL/FVG/OB/BoS + 交易計畫線

## 核心理念（與其他「訊號群」的差別）

1. **先驗證，再公開** — 紙上驗證滿 100 筆且期望值為正之前，不對外推廣任何訊號。
   數據公開，含虧損。
2. **利益對齊** — 收益僅來自交易所返佣。優先扣除 API / 伺服器 / AI 成本（帳單公開），
   剩餘 30% 發起人 / 50% 依貢獻積分分給社群 / 20% 公益捐贈。
   我們不賺你的交易量，不賣課，不收訂閱費。
3. **風控優先** — 單筆固定風險、總曝險上限、日虧 -3% 自動熔斷、
   重大數據發布前後訊號靜默。
4. **開源透明** — 程式碼全開源（Apache-2.0）。你可以完全不參與社群，
   自己跑一套，金鑰永遠只在你自己的機器上。

完整願景與分潤模型見 [VISION.md](VISION.md)。

20+ 個 supervised workers 並行（單一 worker 崩潰自動重啟，不影響其他）。

## 快速開始

```bash
git clone <this-repo>
cd trading-bot
pip install -r requirements.txt
cp .env.example .env        # 填入你自己的 API 金鑰（見檔內註解）
python run_bot.py           # 連續模式
python run_bot.py --once    # 單輪測試
```

最低需求：Telegram Bot Token + 群組（Forum Topics 模式）。
CoinGlass / OKX / 其他 API 金鑰按需填入 — 缺少的數據源會優雅降級。

## 安全紅線（寫死在設計裡）

- API 金鑰只存 `.env`，永不進版控、永不傳給 LLM
- 交易所 key 只開「讀取」權限；交易 key 必須禁提現 + IP 白名單
- 本系統**不碰你的資金、不代操、不託管** — 訊號僅供研究參考

## 免責聲明

本專案為**教育與研究用途**。加密貨幣與衍生品交易具有極高風險，
所有訊號與分析不構成投資建議。過去績效不代表未來表現。
使用本軟體的一切後果由使用者自行承擔。
